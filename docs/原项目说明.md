# 标本柜 SpecimenCabinet

PICO Project Swan 上的全沉浸游戏：一位老博物学家留下一张书桌、一个空柜子和几盒没整理的标本。把甲虫、蝴蝶、矿物、化石认出来，放回该放的地方。

> 2026-11-05 v0.1（versionCode 1）：
> - 十三盒标本，四章，二十件标本。模型质量是这个游戏的重点。
> - 捏托盘上的标本，它升到面前慢慢转；看左边的卡片，点按钮听讲解；在右边回答。
> - 四种玩法：认名字、按类归屉、比硬度（谁能划动谁）、排年代。
> - 尺寸、硬度、年代都用图形表示，不是大段文字。每件标本都有 22–28 秒的讲解录音。
> - 答错会少星，但会给提示。金奖杯解锁隐藏展示。
> - 调试钩子 AutoPilot（logcat 标签 SpecTest）。

场景开局只摆一次，之后转头不会移动它。

真机反馈改了这些：每盒最后一件入柜后，结算页和右侧的“听讲解”面板同时显示（这项只跑了服务器测试，按用户要求没上模拟器）。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`。
